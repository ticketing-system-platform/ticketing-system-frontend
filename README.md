# TiketEvent — Frontend (React + Vite + Tailwind)

SPA untuk customer (lihat event, checkout, bayar via Midtrans Snap, Tiket Saya + QR) dan admin
(dashboard, kelola event & jenis tiket, transaksi, scanner check-in).

Panduan lengkap langkah demi langkah ada di [README utama](../README.md).

```bash
npm install
cp .env.example .env   # isi VITE_API_URL dan VITE_MIDTRANS_CLIENT_KEY
npm run dev            # http://localhost:5173
```
